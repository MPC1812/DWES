    Establece la ruta de acceso a la que se enviarán las peticiones AJAX.


¿Cuál es el propósito del archivo comun.php?
    Contiene funciones que se pueden usar desde cualquier archivo PHP.


¿Porqué index.php incluye setup.php y no el archivo backend.php? Explícalo con tus palabras.
    Porque setup.php es el archivo que se encarga de registrar las funciones para ser usadas desde Javascript y backend.php es el archivo que se encarga de procesar las peticiones AJAX, por tanto, index.php necesita incluirlo para que nuestras interacciones (peticiones AJAX) puedan ser procesadas.
